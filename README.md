# 💍 Royal Interactive Wedding Invitation

An ultra-smooth, luxury interactive wedding invitation card website created exclusively for **Hadia Noor** from **Muhammad Faizan**, celebrating the wedding of **Ayesha Sadiqa** & **Muhammad Faizan**.

Built with **React, Vite, Framer Motion, and Canvas Confetti**.

---

## ✨ Features

- 💌 **3D Sealed Envelope**: Realistic wax seal breaking animation, 3D envelope fold opening, and card emerging.
- 🎴 **Physical Stacked Card Suite**: 8 distinct physical cards stacked in layers with page-lifting 3D turn animations, card spine crease, and "Card X of 8" navigation.
- 💬 **Natural Roman Urdu**: Pure conversational Roman Urdu tailored from Faizan to Hadia.
- 🌹 **Special Memories & Video Scenes (Card 4)**:
  - **Scene 1 • First Date**: With photo (`first-date.jpeg`).
  - **Scene 2 • Second Date**: Video playback (`second-date.mp4`).
  - **Scene 3 • Mera Chand in Red Dress**: Video (`HV5.mp4`) with the romantic promise of making her his bride.
- 💍 **Interactive Nikkah Proposal Game (Card 5)**: "Will you say Qubool Hai?" with romantic options and an unlockable Nikkah promise certificate with confetti showers.
- 🎁 **Gold Scratch Card (Card 3)**: Interactive canvas scratch-to-reveal surprise photo game with particle bursts.
- 👰 **Dulhan Gallery (Card 2)**: The bride's arch gallery with portrait switcher (`A2`–`A6`).
- ⏳ **Live Countdown & Venue Details (Card 6)**: Live countdown to 18 December 2026, 07:30 PM at *The Wedding Court*, with Google Maps link and .ICS calendar export.
- 💌 **Memories & WhatsApp RSVP (Card 7)**: Swipeable memories deck and prefilled WhatsApp RSVP.
- 🎵 **Auto-Playing Music**: Atmospheric wedding song auto-plays when opening the envelope, with a spinning vinyl controller.
- 📱 **Mobile-First & 60fps**: Responsive across all phone and desktop screens.

## 🚀 How to Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Build for production
npm run build
```

## 🌐 How to Deploy

### Option 1: Vercel (Recommended - 1 Click)
1. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
2. Click **"Add New"** -> **"Project"**.
3. Import `devvahmed/wedding`.
4. Framework Preset: **Vite** (detected automatically).
5. Build Command: `npm run build`
6. Output Directory: `dist`
7. Click **"Deploy"**!

### Option 2: Netlify
1. Go to [netlify.com](https://netlify.com).
2. Click **"Add new site"** -> **"Import an existing project"** -> **"GitHub"**.
3. Select `devvahmed/wedding`.
4. Publish directory: `dist`
5. Click **"Deploy site"**.

### Option 3: Standalone Offline File
You can also directly double-click `invitation.html` to run the single-file offline invitation in any browser without needing a server!
